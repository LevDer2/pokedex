# Модальне вікно покемона

`PokemonModal.tsx` — розмітка вікна, `PokemonModal.css` — адаптивні стилі зі світлою та темною темами. Додаткові бібліотеки не потрібні.

## Що вже підключено

У `App.tsx` створено `pokemonModalRef` через `useRef<HTMLDialogElement>(null)`. Обробник `handleOpenPokemonModal` викликає `pokemonModalRef.current?.showModal()`.

Обробник передається через `PokemonCatalog` → `CatalogToolbar` до кнопки «Випадковий покемон». Це відкриття демонстраційного вікна: випадковий вибір та HTTP-запити не додані.

Нативний HTML-елемент `<dialog>` забезпечує модальний режим, утримання фокуса всередині вікна та закриття через Escape. Кнопки закриття знаходяться у `<form method="dialog">`, тому закривають його без запиту та перезавантаження сторінки. Після закриття браузер повертає фокус на кнопку відкриття. Клік по затемненню не закриває вікно.

## Як підключити свої дані

Заміни `demoPokemonDetails` у пропсі `pokemon` на дані вибраного покемона у форматі `PokemonModalData`, який експортується з `PokemonModal.tsx`:

```tsx
<PokemonModal ref={pokemonModalRef} pokemon={selectedPokemon} />
```

Приклад усіх полів — у `src/data/demoPokemonDetails.ts`. Назви, опис, типи та слабкості передаються українською. Зріст і вага — готові рядки з одиницями виміру. `types` і `weaknesses` містять англійський ключ кольору `type` та український підпис `label`.

`stats` містить числові значення `hp`, `attack`, `defense`, `specialAttack`, `specialDefense`, `speed`. Шкали використовують спільний діапазон 0–255, поруч показане саме число. Це CSS-шкали, а не відсоток здоров’я. Якщо `image` порожній, відображається текстова заглушка.

Тему компонент успадковує від `.pokedex-app[data-theme]`. Розміщуй його всередині цієї обгортки, як у поточному `App.tsx`.

## Еволюція та опис здібності

Обидва блоки підтримуються PokéAPI. Дані в демонстрації перевірені за API, але запитів у компонентах немає.

- `abilityDescription?: string` — опис поточної здібності. Якщо він переданий, назва здібності стає кнопкою з іконкою інформації. `PokemonAbility` відкриває нативний `popover`: він закривається кнопкою «Закрити», натисканням поза панеллю або Escape. Якщо опису немає, залишається звичайна назва без порожньої довідки.
- `evolutionPaths?: PokemonEvolutionStage[][]` — шляхи еволюції. Один внутрішній масив — один повний шлях, наприклад `[Бульбазавр, Айвізавр, Венузавр]`. Для розгалужень передай кілька шляхів зі спільним початком: `[Іві, Вапореон]`, `[Іві, Джолтеон]` тощо. Не об'єднуй різні гілки в одну послідовність: Вапореон не еволюціонує в Джолтеона.
- Етап містить `number`, `name`, `image`, `types` та необов'язкове `condition` — умову переходу **від попереднього етапу до цього**. Для Бульбазавра умови — «Рівень 16» перед Айвізавром та «Рівень 32» перед Венузавром.
- `undefined` або порожній масив приховує блок еволюцій. Один шлях з одним покемоном показує повідомлення про відсутність еволюцій; передавай його лише після успішної перевірки повного ланцюжка. Відсутність завантажених даних не означає відсутності еволюцій.

### Звідки взяти дані

1. `/pokemon/{id or name}/`: `abilities[].ability.url` веде до здібності, `species.url` — до виду. Зображення та типи беруться з `sprites.other['official-artwork'].front_default` і `types` кожного покемона.
2. `/ability/{id or name}/`: вибери `effect_entries` з `language.name === 'en'` і візьми `short_effect` або `effect`. Якщо опису немає, можна використати англійський `flavor_text_entries` для потрібної версії гри; якщо немає і його — не передавай `abilityDescription`.
3. Перейди за `species.url`, а потім за `evolution_chain.url` з відповіді виду. Не підставляй ID покемона замість ID ланцюжка — це різні ресурси.
4. `/evolution-chain/{id}/`: дерево починається в `chain`, наступні гілки — `evolves_to`, умови — `evolution_details`. Для зображень і типів кожного виду знайди його стандартний різновид у `varieties` (`is_default === true`), потім завантаж відповідний ресурс `pokemon`.

Умови можуть залежати від версії гри та містити предмет, обмін або кілька вимог одночасно. `min_level` — лише одна з можливих умов, не універсальне правило для всіх еволюцій. Поточний компонент показує готовий рядок, а не обчислює умови. Отримані відповіді варто кешувати.

PokéAPI не надає української локалізації: українські назви й опис у демонстрації перекладені вручну. Для реального API потрібен власний словник перекладів або відображення доступного англійського тексту.

Джерела: [Evolution Chains](https://pokeapi.co/docs/v2#evolution-chains), [Abilities](https://pokeapi.co/docs/v2#abilities), [ланцюжок Бульбазавра](https://pokeapi.co/api/v2/evolution-chain/1/), [Overgrow](https://pokeapi.co/api/v2/ability/overgrow/).
